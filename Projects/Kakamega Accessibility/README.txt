Kakamega Health Accessibility Analysis

This project analyzes access to health facilities in Kakamega County using geospatial data and spatial analysis techniques.

Tools

QGIS

GeoPackage

Project Structure

data/ – contains the spatial data 
maps/ – contains the QGIS project file 

How to Open

Open the project in QGIS.

Load the file located in maps/kakamega-health-accessibility.qgz.

Ensure the folder structure is unchanged so the data paths work correctly.

Purpose

This project demonstrates GIS-based analysis for evaluating spatial accessibility to health facilities.
